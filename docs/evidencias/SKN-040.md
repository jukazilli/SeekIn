# EV-SKN-040 — Domínio transacional de autenticação

**Item:** SKN-040  
**Estado:** Em desenvolvimento  
**Verificado em:** 2026-09-13T00:03:00Z  
**Commit:** a preencher após o fechamento do corte  
**Ambiente:** beta  
**Deploy:** Resend e DNS autoritativo de `soberania.tech`  

## Resultado

O domínio transacional `seekin.soberania.tech` foi criado no Resend na região de São Paulo
(`sa-east-1`), com envio habilitado e recebimento desabilitado. Os registros DKIM e de return path
exigidos pelo provedor foram publicados no DNS autoritativo e o domínio foi marcado como
`verified` pelo Resend. A política DMARC existente no domínio
organizacional é herdada pelo subdomínio porque não define uma política `sp` diferente.

O remetente aprovado para autenticação é `no-reply@seekin.soberania.tech`. Métricas de abertura e
clique não foram configuradas. O SMTP próprio foi ativado no Supabase Auth com a credencial mantida
somente nos provedores. Um convite de teste foi recebido em uma caixa controlada pelo responsável,
mas classificado como spam; novos testes de reputação e conteúdo serão executados quando o fluxo de
autenticação da aplicação estiver funcional.

## Critérios de aceite

| Critério | Resultado | Evidência |
|---|---|---|
| domínio transacional separado de marketing | Passou | `seekin.soberania.tech` verificado no Resend |
| DKIM publicado | Passou | consulta DNS pública ao registro de domínio |
| return path e SPF alinhados | Passou | consultas DNS públicas aos dois CNAMEs exigidos pelo Resend |
| DMARC aplicável ao subdomínio | Passou | política organizacional `_dmarc.soberania.tech`, sem sobrescrita `sp` |
| rastreamento de abertura e clique desativado | Passou | configuração de tracking não habilitada no domínio |
| SMTP próprio no Supabase Auth | Passou | configuração salva com remetente e domínio dedicados |
| entrega transacional inicial | Parcial | convite recebido, porém classificado como spam |
| fluxo completo de cadastro e verificação | Pendente | implementação da aplicação ainda não iniciada |

## Riscos residuais

- a reputação inicial ainda é insuficiente para evitar classificação como spam;
- SKN-040 só poderá ser concluído após cadastro, confirmação e mensagens seguras estarem implementados e testados.

## Rotação de credencial

A primeira credencial de teste foi rotacionada após aparecer em um snapshot temporário da automação.
O artefato local foi removido e a credencial ativa foi inserida diretamente pelo responsável, sem
ser registrada no repositório ou nesta evidência.

## Rollback

Desabilitar o envio do domínio no Resend e remover somente os três registros exclusivos de
`seekin.soberania.tech`. Não alterar os registros dos demais produtos em `soberania.tech`.
