## Resultado

O Worker Beta passou a oferecer `GET /health?mode=readiness`. A rota exige um Bearer token, encaminha
o token e a correlação ao `GET /functions/v1/health?mode=readiness` do Supabase Beta e só declara
sucesso depois que a Edge Function confirma a execução de `foundation_health()` no banco.

O smoke partiu de um Chromium real aberto na aplicação Beta. A resposta final foi `200 HEALTH_OK`,
identificou o ambiente `beta`, devolveu o SHA implantado e comprovou a mesma correlação no navegador,
Worker e backend. A consulta de banco foi feita pela Edge Function com privilégios do usuário
autenticado, sem leitura de tabela ou conteúdo de aluno.

## Riscos residuais

- O smoke prova a fundação técnica, não uma jornada funcional do planner, que permanece bloqueada até
  o fechamento de G2.
- A Edge Function informa a versão semântica `0.1.0`; o SHA verificável do corte é o SHA do Worker
  retornado ao navegador.
- Um trace bruto do navegador não foi persistido porque incluiria o header Authorization. A evidência
  registra apenas a projeção sanitizada necessária para reproduzir a cadeia.
