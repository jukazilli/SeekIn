## Riscos residuais

- A hidratação atual do React Router usa scripts inline; por isso a CSP permite `unsafe-inline` em
  `script-src` e `style-src`. Nonces e CSP estrita ficam para a revisão de segurança do SKN-132.
- A URL `workers.dev` é pública, mas ainda não expõe funcionalidade nem dados de aluno.
- O smoke navegador → web → Edge Function → banco e a readiness autenticada pertencem ao SKN-027.
- `workerd`, PowerShell e `curl` locais continuam afetados pelo runtime/proxy do Windows; o HTTPS
  remoto foi validado em Chromium real.

## Rollback

O Worker Beta usa versões imutáveis da Cloudflare. Uma versão anterior pode voltar por promoção de
versão sem rollback de banco. O ensaio formal, incluindo prova da versão restaurada, pertence ao
SKN-029.

## Observações

O primeiro deploy (`7e1928a4-7a1c-44de-8a50-5f5850ae3d24`) revelou bloqueio da fonte inline pela
CSP e não é uma versão aprovada. O Playwright detectou a violação; `font-src 'self' data:` foi então
adicionado, testado e publicado na versão canônica acima.
