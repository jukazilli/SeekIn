## Riscos residuais

- Existe um único custodiante e nenhum substituto para recuperação de conta.
- Zero aprovações humanas é uma exceção temporária compensada por PR e CI, não uma separação real de
  funções.
- O deploy via Wrangler permanece manual; o environment `beta` do GitHub ainda não é um gate técnico
  desse comando.
- Workers Free não disponibiliza budget alert de cobrança; o controle atual usa hard limit e revisão
  manual.
- Supabase Free pode pausar e não oferece recuperação adequada a produção.

registrando motivo e restauração imediata da proteção. Alterações documentais retornam por pull
request de reversão. Nenhum rollback de aplicação ou banco é necessário porque não houve deploy nem
mudança de schema.
